**Dynamic AVL Tree System**

**Overview**
  Dynamic AVL Tree System is a menu-driven C++ application that implements a self-balancing AVL Tree.
  It supports insertion, deletion, searching, tree traversals, and displaying tree height, minimum 
  and maximum values, node count, and tree structure.

**Features**
  - Insert multiple values into the AVL tree
  - Search and delete values
  - Automatic balancing using LL, RR, LR, and RL rotations
  - Inorder, preorder, and postorder traversals
  - Find minimum and maximum values
  - Display tree height and total nodes
  - Show the root's balance factor
  - Display the tree structure
  - Check whether the tree is empty
  - Validate integer input and prevent duplicate values

**Technologies Used**
  - C++
  - Data Structures and Algorithms
  - AVL Trees
  - Structures and Classes
  - Pointers and Recursion
  - Dynamic Memory Allocation
  - Input Validation

**How to Run**
  1. Open the project in Visual Studio or another C++ IDE.
  2. Compile the source code.
  3. Run the application.
  4. Select an operation from the menu.
  5. Enter the required values.

**Project Purpose**
  This project demonstrates the implementation of a self-balancing binary search
  tree and helps develop an understanding of tree operations, recursion, pointers,
  rotations, and dynamic memory management in C++.
